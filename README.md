# DreamFolder

[360文件夹](https://github.com/NeglectDream/DreamFolder) 的 Rust 原生重写：多标签文件管理器，纯 Win32 自绘 UI，面向极致冷启动速度。

> **状态：未完全可用。** 这是一个仍在开发中的实现，日常使用请以 Windows 资源管理器为准。
>
> 已知不可用或不完整的地方：
>
> - **右键菜单的「新建」不是系统原生的那一套**。Windows 的「新建」命令依赖宿主的 `IShellView` 来创建文件并进入重命名，本项目是自绘列表，没有这个视图，直接调用会一律返回 `E_FAIL`（已用三种方式验证）。因此「新建」子菜单由本项目自己填充和执行，类型来自注册表 `ShellNew`，可选项比资源管理器少（本机实测 5 项 +「文件夹」），Word / Excel 这类没有 `ShellNew` 注册的类型不会出现。
> - 「新建」子菜单的行高、图标与相邻的系统菜单项可能有细微差异。
> - 「新建」的类型表在启动时扫描并缓存，新装软件注册的类型需要重启才会出现。
> - 接管 Windows 文件管理器、标签归类、系统索引搜索等功能虽已实现，但覆盖的异常路径有限，未做长期稳定性验证。
>
> 欢迎提交 issue，但请预期这是一个进行中的项目。

## 特性

- **多标签**：每标签独立的历史、搜索与选中状态
- **八档视图**：超大 / 大 / 中 / 小 / 列表 / 详细信息 / 平铺 / 内容，图片文件显示缩略图
- **三栏布局**：书签栏、导航窗格、详细信息窗格（可逐项开关）
- **深浅双主题**，界面缩放 125% ~ 300%
- **中文输入友好**：自绘输入框全部接入 IME，候选窗跟随光标
- **每标签搜索**：系统索引 + 子树扫描，后台执行不卡界面
- **标签归类**：按路径给文件打标签，导航窗格按标签分组
- **系统接管**：可接管 Windows 文件管理器，随时一键恢复
- **单实例**：重复启动投递路径给已有窗口

## 构建

要求 Rust 1.75+，仅支持 Windows 10 及以上。

```
cargo build --release
```

产物：`target/release/DreamFolder.exe`
